# PSG Sons Charities Website

This repository contains the source code for the official PSG Sons Charities website. The project is built with React (fullpage.js), Vite, and Tailwind CSS, and deployed using Nginx inside Docker.

## 🎯 Features

### 🎨 Design System

- **Color Palette**: Carefully curated colors for brand consistency
- **Typography**: Responsive font scaling with proper hierarchy
- **Spacing System**: Consistent padding and margins following 8px grid
- **Animations**: Smooth transitions and parallax effects for engaging UX
- **Responsive Design**: Mobile-first approach with breakpoints for all devices
- **Component Library**: Reusable UI components for consistency

### 📦 Tech Stack

- **Frontend Framework**: React 18.x
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Scroll Effects**: Fullpage.js for full-screen sections
- **Runtime**: Node.js
- **Containerization**: Docker with Nginx
- **Version Control**: Git
- **Package Manager**: npm/pnpm
